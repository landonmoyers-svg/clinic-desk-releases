# Clinic Desk — downloads

Installers for **Clinic Desk**, the clinic app used at Lone Peak Psychiatry.

This repository holds the built application only. There is no source code here.

## Install

1. Open [Releases](../../releases/latest) and download the `.zip`.
2. Unzip it.
3. Drag **Clinic Desk** into your **Applications** folder.
4. Open it and answer the first-run setup.

Apple Silicon Macs. The app is signed and notarised by Apple, so it opens without
security warnings.

## Updates

Clinic Desk checks here for new versions and tells you when one is ready. It never
installs anything on its own — you choose when to replace it.
